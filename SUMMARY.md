# Warehouse Operational Assistant - Project Summary

This repository implements a production-grade, NVIDIA Blueprint-aligned AI-powered warehouse operational assistant featuring a sophisticated multi-agent architecture with specialized agents for Equipment & Asset Operations, Operations Coordination, and Safety & Compliance, all orchestrated through LangGraph with comprehensive Model Context Protocol (MCP) integration for dynamic tool discovery and execution. The system leverages NVIDIA's enterprise AI stack including Llama 3.1 70B for natural language understanding, NV-EmbedQA-E5-v5 for high-quality 1024-dimensional embeddings enabling GPU-accelerated vector search through Milvus, and a complete NVIDIA NeMo document processing pipeline for intelligent OCR and structured data extraction from warehouse documents like invoices and BOLs. At its core, the assistant features a hybrid RAG (Retrieval-Augmented Generation) architecture combining PostgreSQL/TimescaleDB for structured data with advanced vector search optimization including intelligent chunking (512-token chunks with 64-token overlap), multi-factor evidence scoring, context-aware clarifying questions, and smart query routing that automatically classifies queries between SQL, vector, and hybrid retrieval paths, supplemented by Redis caching achieving 85%+ hit rates for optimal performance. The system includes a comprehensive AI-powered demand forecasting engine with a 6-model ensemble (XGBoost, Random Forest, Gradient Boosting, Linear Regression, Ridge Regression, SVR) achieving 82% accuracy and 15.8% MAPE, complete with advanced feature engineering, Optuna-based hyperparameter optimization, NVIDIA RAPIDS GPU acceleration support, and automated reorder recommendations, all exposed through a modern React-based UI with real-time chat interface, forecasting dashboard, MCP testing panel, and enterprise-grade security (JWT/OAuth2 with RBAC across 5 user roles). Beyond the core AI capabilities, the platform integrates seamlessly with enterprise warehouse systems through unified adapters for major WMS platforms (SAP EWM, Manhattan, Oracle WMS), comprehensive IoT integration supporting multiple protocols (HTTP, MQTT, WebSocket, Modbus, BACnet) for equipment monitoring, environmental sensors, safety systems, and asset tracking (RFID/Barcode), ERP systems for customer/order/inventory synchronization, and time & attendance systems, all monitored through production-grade Prometheus/Grafana dashboards with real-time system health metrics, equipment telemetry tracking (battery levels, temperature, charging status across 2,880+ data points), and comprehensive observability featuring NeMo Guardrails for content safety and compliance validation, making this a complete enterprise solution for intelligent warehouse operations management.
